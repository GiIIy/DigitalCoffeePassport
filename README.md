# Digital Coffee Passport

## Project Overview

**Digital Coffee Passport** is a web-based application that allows users to explore and track different coffee varieties from Starbucks. It provides a detailed coffee profile including information such as the coffee's origin, flavour notes, brewing methods, and more. Users can also store notes about the coffees they've tried, helping them build a virtual passport of their coffee experience.

---

## Features

- **Coffee Profiles**: Detailed pages for each coffee, including information such as:
  - Coffee Name
  - Flavour Notes
  - Growing Region
  - Body, Acidity, and Processing Method
  - Food Pairings
  - Brewing Methods
  - Roast Levels
- **Notes Feature**: Users can write notes for each coffee they try and store them locally.
- **Search & Filter**: Search coffees by name and filter by roast type.
- **Contents Page**: A comprehensive listing of all available coffees.
- **Responsive Design**: The app is responsive and works well on both desktop and mobile devices.

---

## Future Features

- **User Accounts**: The option for users to create an account and save their coffee preferences.
- **Coffee Ratings**: Allow users to rate coffees and provide feedback.
- **Mobile App Version**: Potential future mobile app version for easy access while on the go.
